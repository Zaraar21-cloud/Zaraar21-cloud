## Featured Projects

### FindR

Multi-tenant lost and found platform that replaces the shoebox behind the front desk. Staff photograph a found item and a vision model fills in the descriptive attributes on its own, cataloguing it in under fifteen seconds.

Seekers search in plain language rather than picking from dropdowns. Matches come back without ever exposing the private details that make a claim verifiable, and claiming is where it gets interesting: the platform generates verification questions from those private attributes, so only the real owner can answer them. A verified claim then moves to an in-person handover backed by an append-only audit trail.

Unredacted images and sensitive details are never shown to unverified users, and a single codebase and database serve many organizations with strict data isolation between them.

Built with Next.js 15, React 19, TypeScript, Tailwind CSS v4 and Supabase, laid out as a workspace monorepo with privacy constraints covered by tests.

[Repository](https://github.com/charan27teja/FindR/) &nbsp;·&nbsp; [Live beta](https://findr-web-five.vercel.app/)

### AscendAttendance_Logger

Single-use QR attendance system that replaced the paper register at the Sreenidhi Ascend Incubation Centre. A code appears on the centre's screen, a member scans it with their phone, and the visit is written straight into a Google Sheet.

The interesting part is the token. Spending it is a read-then-delete inside a Firestore transaction, so if two phones scan the same code at the same instant, exactly one wins. Every code dies the moment it is used or after thirty seconds, which makes a photographed screenshot worthless. An earlier version used geolocation, until it turned out to be spoofable from the browser console in one line.

Built with vanilla JavaScript, Firebase Hosting, Firestore and Google Apps Script. No build step, no framework, and three plain Node test scripts covering the session windows, the QR rotation invariant and the check-out flow.

[Repository](https://github.com/Zaraar21-cloud/AscendAttendance_Logger) &nbsp;·&nbsp; [Live app](https://ascend-attendance-logger.web.app/)

### Attendify

Attendance calculator that starts from a photograph. Upload a picture of your timetable and client-side OCR parses it into an editable weekly grid, then the calculator tells you exactly how many classes you need or how many you can safely skip to hit your target percentage.

There is also a what-if simulator for toggling planned attendance across upcoming days. Everything runs in the browser, so no timetable or attendance data ever leaves the device.

Built with Next.js 16, React 19, TypeScript, Tailwind CSS v4 and Tesseract.js, wrapped in a high-contrast neubrutalist interface.

[Repository](https://github.com/Zaraar21-cloud/Attendify)
